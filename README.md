# 🎨 티스토리 반응형 블로그 스킨 (Custom Odyssey) Edition 2.

카카오 공식 **Odyssey (오디세이) 스킨**을 기반으로 가독성, 현대적인 모던 뉴트럴 컬러 시스템, 1480px 와이드 레이아웃, 3열/4열 4:3 카드 그리드, 상단 메가메뉴, 모바일 반응성, 그리고 마크다운 다이어그램을 대폭 개선한 프리미엄 커스텀 티스토리 스킨입니다.

## ✨ 주요 특징 및 개선 사항

### 1. 🖥️ 와이드 콘텐츠 레이아웃 (최대 폭 1480px)
- **넓고 시원한 개방감**: 전체 컨테이너 폭을 기존 1240px에서 **1480px**로 시원하게 확장
- **쾌적한 본문 영역**: 글 상세 페이지 본문 영역(`article-view-main`)이 **약 1160px**로 확보되어 고해상도 와이드 모니터 환경에서 이미지, 긴 문장, 소스 코드 블록이 답답함 없이 미려하게 표현됨
- **완벽한 수직 정렬 라인**: 헤더, 메인 배너, 본문, 하단 위젯, 푸터의 가로폭을 모두 1480px로 일치시켜 통일감 있는 그리드 완성

### 2. 🎨 모던 뉴트럴 & 비비드 오렌지 컬러 팔레트
- **배경색**: 눈의 피로를 최소화하는 차분한 오프화이트 (`#FAFAF8`)
- **본문 텍스트**: 또렷하고 세련된 소프트 블랙 (`#222222`)
- **보조 텍스트**: 은은하고 부드러운 그레이 (`#888888`)
- **구분선/테두리**: 깔끔하고 정제된 모던 라인 (`#EAEAEA`)
- **포인트 악센트**: 시선을 사로잡는 생동감 넘치는 비비드 오렌지 (`#F05A3C`)

### 3. 🖼️ 메인 페이지 3열 수직 카드섹션 (표준 4:3 썸네일)
- **3열 독립 박스 디자인**: 카테고리별 최신글을 1줄에 3개씩 균등 배치 (`repeat(3, minmax(0, 1fr))`)
- **표준 4:3 썸네일 비율**: 왜곡 없는 황금 비율(`aspect-ratio: 4 / 3`) 적용 및 마우스 호버 시 부드러운 줌(`scale(1.05)`) 인터랙션
- **완성도 높은 카드 UI**: 순백색 배경(`background: #ffffff`), 테두리 라인(`border: 1px solid #EAEAEA`), 모서리 라운딩(`8px`), 은은한 입체 그림자(`box-shadow`)
- **간결한 타이포그래피**: 2줄 말줄임 세리프 제목 + 하단 정렬된 작성일로 단정하고 미니멀한 레이아웃

### 4. 📂 서브메뉴(카테고리 목록) 4열 카드 그리드 & 1번째 글 하이라이트
- **1번째 최신글 가로형 하이라이트**: 상단에 4:3 썸네일(`360px × 270px`) + 상세 요약문/메타가 결합된 1면 포커스 기사 레이아웃 유지
- **2번째 글부터 견고한 4열 그리드**: CSS Grid(`repeat(4, minmax(0, 1fr))`)를 적용하여 밀림 없이 정확히 1줄에 4개씩 균등 배치
- **메인 카드와 100% 동일한 박스 디자인**: 서브메뉴 4열 카드에도 순백색 카드 박스, 모서리 라운딩, 4:3 썸네일, 호버 효과를 완벽 일원화

### 5. 📰 신문/뉴스 포털형 최신글 5개 헤드라인 레이아웃
- **언론사 1면 스타일 헤드라인**: 메인 화면 상단에 5개 기사를 포털 1면 스타일로 구성
  - **1번 Hero 기사**: 상단 대형 제목 + 좌측 큼직한 썸네일 + 우측 상세 본문 요약문
  - **2, 3번 Sub 기사**: 좌측 하단 2열에 좌측 썸네일 + 우측 제목/요약문 배치
  - **4, 5번 Side 기사**: 우측 세로 구분선 분할 영역에 상단 와이드 썸네일 + 하단 제목/서브텍스트 배치
- **홈 커버 및 자동 로딩 지원**: 티스토리 홈 커버(`news-headline`) 지원 및 커버 미설정 시에도 메인에서 최신글 5개 자동 렌더링

### 6. 🧭 상단 드롭다운 메가메뉴 (Mega Menu)
- **1차 카테고리 버튼형 UI**: 마우스 호버 시 부드러운 인터랙션 제공
- **풀와이드 드롭다운 서브메뉴**: 2차 카테고리를 한눈에 확인할 수 있는 메가메뉴
- **글 개수 & 새 글 배지**: 각 서브메뉴 옆에 **작성된 글 개수 `(숫자)`** 및 **새 글 `[N]` 배지**를 가지런히 수평 정렬
- **높이 자동 반응**: 카테고리 항목 수에 따라 드롭다운 높이가 자동으로 확장되는 스크립트 내장

### 7. 🔤 단정하고 미려한 타이포그래피
- **본문**: 가독성이 뛰어난 산세리프 폰트 `Pretendard` 적용
- **제목/헤더**: 격조 있고 단정한 세리프 폰트 `Noto Serif KR` 적용

### 8. 🏆 포스팅 본문 우측 카테고리 최신글 10개 랭킹 위젯
- **뉴스 포털 스타일 1~10 순위 리스트**: 글 본문 우측에 해당 카테고리의 최신 글 10개를 번호 순위와 함께 일목요연하게 표시
- **Sticky 스크롤 인터랙션**: PC 화면에서 본문을 스크롤할 때 우측에 계속 고정되어 머무르며 추가 탐색 유도
- **반응형 스택**: 1060px 이하 모바일 화면에서는 본문 하단으로 자연스럽게 전환

### 9. 📐 슬림 메인 배너 & 50% 슬림화된 하단 위젯/푸터
- **슬림 프로모션 배너**: PC 배너 높이를 260px, 모바일은 230px로 슬림화하여 첫 화면에서 본문 콘텐츠가 즉시 노출
- **50% 슬림 하단 위젯**: '최근 댓글' 및 '방문자수(Total / Today / Yesterday)' 위젯의 상하 여백과 폰트를 50% 수준으로 컴팩트하게 압축
- **푸터 여백 축소**: `#footer` 상단 마진을 20px로 축소하여 불필요한 스크롤 방지

### 10. 📊 Mermaid 다이어그램 자동 렌더링 지원
- 티스토리 마크다운 에디터 사용 시 발생하는 코드 블록 내 줄바꿈 깨짐 현상을 자동으로 감지 및 보정하는 스크립트 내장
- `mermaid` 플로우차트, 시퀀스 다이어그램 등의 매끄러운 렌더링 지원

### 11. 📱 모바일(스마트폰) 환경 완벽 최적화
- **1열 반응형 수직 카드**: 767px 이하 모바일 화면에서 4:3 썸네일과 제목이 결합된 자연스러운 1열 카드 레이아웃 전환
- **모바일 햄버거 드로어**: 터치 환경에 최적화된 사이드바 메뉴 열기/닫기 및 닫힘 시 화면 터치 프리징 방지

## 🚀 사용 및 적용 방법

> [!IMPORTANT]
> **반드시 티스토리 기본 `Odyssey (오디세이)` 스킨을 먼저 적용한 후 HTML/CSS 편집을 진행해야 기본 리소스 및 치환자가 정상 동작합니다.**

1. **티스토리 블로그 관리자 홈**에 접속합니다.
2. 좌측 메뉴에서 **꾸미기 > 스킨 변경**으로 이동합니다.
3. 티스토리 기본 제공 스킨 중 **`Odyssey (오디세이)` 스킨을 선택하고 [적용]**합니다. *(※ 필수 사전 작업)*
4. 좌측 메뉴에서 **꾸미기 > 스킨 편집**을 클릭한 후, 우측 상단의 **[html 편집]** 버튼을 클릭합니다.
5. **HTML 편집**:
   - 상단 **`HTML`** 탭을 선택합니다.
   - 본 저장소의 [`skin.html`](skin.html) 전체 코드를 복사하여 기존 코드를 모두 지우고 붙여넣습니다.
6. **CSS 편집**:
   - 상단 **`CSS`** 탭을 선택합니다.
   - 본 저장소의 [`style.css`](style.css) 전체 코드를 복사하여 기존 코드를 모두 지우고 붙여넣습니다.
7. 우측 상단의 **[적용]** 버튼을 클릭하여 저장을 완료합니다.
